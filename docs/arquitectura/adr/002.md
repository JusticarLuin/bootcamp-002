## 1. Contexto y Declaración del Problema

Se utilizará Kong API Gateway como punto de entrada único para dirigir las solicitudes hacia el sistema legado o hacia los nuevos servicios, según avance la migración. Esto permitirá aplicar el patrón Strangler Fig sin afectar a los consumidores de la aplicación, ya que las rutas podrán modificarse progresivamente sin cambiar la forma en que los clientes acceden al sistema.

Además, Kong ofrece funcionalidades de autenticación, control de tráfico, balanceo de carga, monitoreo y gestión centralizada de APIs. En caso de problemas con un nuevo servicio, facilitará redirigir temporalmente las solicitudes al sistema legado, reduciendo el riesgo de interrupciones y ayudando a mantener la disponibilidad durante la modernización.
